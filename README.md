# JAMS-Studios

JAMS Studio is ontstaan vanuit het idee dat leren niet saai hoeft te zijn. Door lesstof uit de biologie te verweven met echte RPG-mechanieken zoals co-op, klassen en crafting, maken we complexe processen op celniveau tastbaar en leuk om te ontdekken. Onze game geeft jou de mogelijkheid om met tot wel 4 personen samen te spelen.
